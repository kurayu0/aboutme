Background & Philosophy

B.E. CSE • Artificial Intelligence • CU

I am an engineering student at Chandigarh University (UID: 25BAI10052) fascinated by how abstract software principles translate into physical transistors and clock cycles. Having completed my Class 10th and Class 12th schooling from Army Public School Chandimandir with a strong foundation in Science & Mathematics, I am dedicated to bridging low-level computation with cutting-edge artificial intelligence.

Too often, modern machine learning and high-level software development overlook the underlying computational constraints. My goal is to build deep mastery of both worlds: understanding cache hierarchies, memory alignment, pipeline hazards, and number systems in Computer Organization & Architecture (COA), while engineering scalable neural architectures in PyTorch and building responsive software.

Whether optimizing matrix multiplication operations or building educational interactive tools for university peers, I value mathematical clarity, deterministic behavior, and clean code craftsmanship.
